# Cambio Mano a Mano · La Calera

Página para registrar cambios mano a mano (vendedor con DNI) y generar el Excel (administración).
El padrón de vendedores y clientes va cifrado (AES-GCM) y se guarda en línea mediante Google Apps Script.
